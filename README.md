## 👨‍💻 About Me

I am a college student and a full-stack-oriented developer with practical experience in frontend, backend, databases, automation, and design. My main stack includes **TypeScript, JavaScript, React, Node.js, Python, PHP, SQL, and MySQL**.

I enjoy working on complete products rather than isolated code examples. I also use AI-assisted tools such as **OpenCode** to research solutions, debug problems, and improve my development workflow.
